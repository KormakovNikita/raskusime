Политика конфиденциальности

Сервис Раскуси уважает частную жизнь пользователей и обрабатывает только данные, необходимые для оказания услуги.

1. Какие данные могут обрабатываться

  • необязательные имя, пол и текст вопроса, которые вы вводите в форму;
  • технические данные платежа (идентификатор заказа, статус оплаты);
  • стандартные технические логи сервера (IP, user-agent) при обращениях к сайту.

2. Цели обработки

Данные используются для создания платежа, генерации персонализированного текста предсказания и обеспечения безопасности сервиса.

3. Передача третьим лицам

Для оплаты данные передаются платёжному провайдеру Т-Банк в объёме, необходимом для эквайринга. Для генерации текста вопрос может передаваться провайдеру языковой модели (OpenAI или совместимому API) без платёжных реквизитов карты.

4. Хранение

Заказы и связанные с ними поля формы хранятся временно в памяти сервера и удаляются после выдачи предсказания или по истечении срока жизни заказа. Платёжный провайдер хранит данные согласно своей политике.

5. Права пользователя

Вы можете не указывать имя и вопрос. Для запросов об удалении или уточнении данных свяжитесь с оператором сервиса через контакт, указанный на сайте после публикации.

Документ будет уточнён под юридическое лицо и домен при запуске в прод.
